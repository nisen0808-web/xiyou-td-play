# 西游X

公开可玩的网页版，程序版本号是 **0.8.7**。

合并到 `main` 并且 GitHub Pages 构建成功之后，现有地址才会换成这一包：

- https://nisen0808-web.github.io/xiyou-td-play/
- https://nisen0808-web.github.io/xiyou-td-play/index-split.html
- https://nisen0808-web.github.io/xiyou-td-play/xiyou-survivors.html

`xiyou-survivors.html` 与 `index.html` 是同一份字节。轻入口 `index-split.html` 还需要同目录的 `assets/`、`chunks/`、`bossfight/`、`villain/`。

第二关起先布阵再开战，天兵守在路线旁的塔位上。第三关起可以排天兵阵型和留守阵型。第一关仍是原来的赶路教学。

开局会带你点开战斗顶部的「Lv · 经验」：那里是加点、技能升级费用和全队强化。可跳过。再看的入口是：开始取经 → 出发页「更多」（洞府阁）→「新手教程」，不清存档。桌面顶栏经验条旁有「Tab 修行」。自动加点默认关，只有自己打开才会花技能点。
